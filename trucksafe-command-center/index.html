SUA EQUIPE VIRTUAL

Agentes

Cada agente tem uma função clara. O coordenador reúne os resultados em uma única conversa.

✳

01 · Coordenador / Tech Lead

Interpreta pedidos, cria o plano de trabalho, identifica dependências, divide subtarefas e consolida conclusões sem esconder incertezas.

Orquestração
⌖

02 · Especialista de Mapas

Investiga renderização, zoom, tiles, cache, mapas baixados, comportamento offline e integração com o sistema de rotas.

Análise técnica
⌘

03 · Engenheiro de Código

Propõe alterações pequenas, explica arquivos afetados e prepara mudanças isoladas. Não deve aplicar mudanças destrutivas por conta própria.

Implementação supervisionada
✓

04 · QA / Testes

Define passos de reprodução, casos de teste, critérios de aceite e validações como análise estática e testes automatizados.

Verificação independente
Nesta versão, os quatro perfis são uma definição de produto. No modo demonstração, as respostas são simuladas; com backend e provedor de IA configurados, o coordenador pode fazer uma análise real do pedido, mas ainda precisará de acesso explícito ao repositório para analisar o código.

Backend da central

A interface pode rodar como arquivo HTML, mas chamadas reais de IA precisam passar por um backend. O pacote inicial inclui um servidor Node.js local.

Endereço do servidor que executa chamadas de IA e aplica as regras de acesso. Para uma instalação local, use a porta 3000.
Status: não testado

Provedor de IA

Configure as credenciais somente no servidor, nunca no HTML.

Para ativar respostas reais no pacote local: copie .env.example para .env, preencha GEMINI_API_KEY e inicie o servidor. A chave será lida apenas pelo Node.js. O modelo pode ser definido em GEMINI_MODEL.

Acesso ao código do TruckSafe

Sem arquivos ou integração autorizada, os agentes conseguem planejar a investigação, mas não confirmar a causa de um bug nem editar o projeto.

Próxima etapa: conectar um repositório privado com permissões mínimas ou importar os arquivos relevantes. O acesso de escrita deve continuar bloqueado por padrão.

Política de aprovação

Configuração inicial do controle humano.

Não use esta central com chaves de API no código do navegador. Não execute código gerado por IA diretamente no seu computador ou servidor de produção.
